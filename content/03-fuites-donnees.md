# Les fuites de données

_À compléter : ce qu'est une « database breach » — un service se fait voler sa base d'utilisateurs (emails + mots de passe)._

## Pourquoi ça vous concerne

- Vos identifiants circulent, même si **vous** n'avez rien fait de mal
- Un mot de passe **réutilisé** → tous vos comptes tombent d'un coup
- C'est LA raison d'avoir un mot de passe **unique** par service

- _À compléter : `haveibeenpwned.com` (expliquer l'usage)_
