# Checklist

_À compléter : appliquer les principes précédents, app par app. Checklist concrète des réglages à vérifier._

## Modèle de checklist par app

Pour chaque application : **MFA activé · permissions revues · confidentialité réglée · à jour**.

### Email _(ex. Gmail / Outlook)_
- [ ] MFA activé

### Messagerie _(ex. WhatsApp / Signal)_
- [ ] Chiffrement / verrouillage

### Réseaux sociaux _(ex. Instagram / Facebook)_
- [ ] Compte privé / visibilité

### Banque
- [ ] MFA + alertes


## Mots de passe
- Unique + long, dans un gestionnaire
- MFA sur les comptes critiques

## Emails
- Vérifier expéditeur, langue, liens avant de cliquer
- Dans le doute, aller sur le site soi-même

## Wifi public
- Rien de sensible sur un réseau ouvert
- Partage de connexion ou VPN de confiance
